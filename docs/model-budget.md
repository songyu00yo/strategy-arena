# 模型接入与费用更新

## 用户最新要求

2026 年 11 月 5 日，用户确认后续使用 OpenAI 官方 API，并指定主模型为 GPT-6.1 Terra。API 预算上限为 200 美元。此要求覆盖此前“模型预算 120 元”的后续开发安排；DeepSeek 历史账目仍按人民币保留，不改写原始数据。

本页是接入决定和验收要求，尚未表示适配器、密钥或新限额已经生效。固定 v0.2.0 的配置仍为 DeepSeek，历史评测只能解释该历史模型与协议。核账期间已停止本机真实预览，不自动恢复付费入口。

## 模型选择

按用户要求，后续主模型选择 `gpt-6.1-terra`。它支持函数调用、结构化输出和图像输入，适合先完成文字竞技，再接入截图。所有竞技角色和三组主实验使用同一模型、同一推理档位和同一预算规则，不通过混用更贵模型制造质量差异。

2026 年 11 月 5 日核对的 [官方模型目录](https://developers.openai.com/api/docs/models) 和 [官方价目表](https://developers.openai.com/api/docs/pricing) 列出标准服务基础价：每百万输入 Token 1 美元、输出 Token 5 美元。该价格不能替代账户可用性及最终账单；缓存、长上下文、服务档位和额外工具计费须按实际适用规则记录。不会把本聊天的模型权限当作用户 API Key 已有权限。

接入时先确认账户可用模型和固定版本标识。支持不可变快照时固定快照；只能使用别名时记录这一限制，不伪称快照。默认先用标准服务和 low 推理档位，以小额开发案例验证质量与延迟，再决定是否统一改档。不会自动升级到 Astra 或切换其他供应商。

## 分阶段预算与启用条件

| 阶段               | 预算上限 | 执行要求                                                    |
| ------------------ | -------: | ----------------------------------------------------------- |
| 适配与小样本联调   |  10 美元 | 先通过无密钥测试，再做少量真实请求；首次试运行最多 2 美元。 |
| 冻结对照与问题复核 |  40 美元 | 先公布请求数、Token 上界、预计费用及停止条件，再启动批次。  |
| 真实试用与演示     |  70 美元 | 每访客、每局及条件重赛共同限额，统计失败与修复调用。        |
| 最终验收与评审预留 |  80 美元 | 开发期不动用。                                              |
| 合计               | 200 美元 | 所有工作区、命令与部署合并核账，不能分别再获得 200 美元。   |

金额上限不能代替调用上限。接入前补齐按批次的请求次数、输入与输出 Token 上限和费用预留；达到任何一项即停止后续请求。记录缓存输入但不重复计入总输入。推理 Token、工具调用及未知响应按供应商实际计费口径处理。未知请求保留预留，不静默重试。

应用账本需要明确货币。现有 CNY 字段不得直接塞入美元，也不得只把 200 写进现有人民币额度变量。由 Codex 在独立分支完成适配与账本方案，保留迁移和跨版本恢复测试；Claude 不负责修改这一范围。

密钥由用户在本地私有配置中填写，不进入聊天、仓库或 Claude 工作区。没有密钥时，只做结构与协议测试，不声称已连通官方 API。目前未创建或充值任何 OpenAI 账户，也没有新增 OpenAI API 请求。
