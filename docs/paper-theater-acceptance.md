## 动作与修复

| 业务节点       | 当前动作                                           |
| -------------- | -------------------------------------------------- |
| 需求进入 A     | 原需求纸面保持可见，等待 A 内容可见后翻合、传递    |
| 相邻角色交接   | 当前卡片轻抬，墨线连接下一实际调用角色             |
| 展开问题       | 小纸面从测量位置展开，背景卡片停稳                 |
| 阅读问题       | 按问题组停读，组间连续滚动                         |
| 选择或填写     | 指针沿曲线减速到达控件，选项轻压，保存文本逐字出现 |
| 确认回答       | 原按钮轻压，确认状态更新，回答收拢成纸条           |
| 继续细化与查漏 | 纸条交给后续实际角色，C 返回补问时再次展开原纸面   |
| 最终交接       | 当前确认完成后纸条送入原结论区，朱红印章落定       |

反馈、展开、翻合、交接和落印的基础时长分别为 160、420、360、600 和 280 毫秒。播放速度同时作用于这些动作。暂停保留当前姿态，跳转显示目标步骤的稳定状态。

每帧由共享时间轴更新纸面、指针和滚动。React 在字符、选择、确认和步骤边界更新内容。控件位置集中测量并缓存，换题、尺寸变化或内容重排后重新测量。纸面使用 transform，阴影由独立装饰层承载，正文保留可读底层。

本轮实际复核还修复了以下问题。

- 忽略已释放纸面的迟到采样，避免旧动作干扰新步骤。
- 将手机底部 7 像素留白并入上一段滚动，消除多余的停读和微移。
- 连续录像复现了手机印章顶边裁切，现按最大旋转及缩放外框限定落印位置。
- 入口纸张副本继承原表单的 800 毫秒淡入，曾在交接前变透明。副本现取消这段重复动画，保持可见，再执行自己的交接。
- 印章落定后保持墨迹，确认按钮及选项沿实际控件轻压并复位。

纸面来源和接收位置取自实际元素。窄屏中 B 卡片处于屏外时，展开来源使用当前舞台平面，页面数据属性记录回退原因。结论处于舞台裁剪区域外时，临时纸条延续相同位置与比例，完成后释放。
