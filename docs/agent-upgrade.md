# 自主推演与历史恢复

## 使用方式

新建讨论默认启用自主推演。系统先生成计划，再生成 A、B、C 三条独立路线。模型在取证后决定补查、追加一轮质疑或进入裁决。页面显示当前计划、实际动作、工具次数和实时生成文字。

每版最多执行 3 次规划、2 轮讨论、20 次模型请求和 12 次工具调用，其中联网最多 6 次。模型请求次数包含规划、提案去重和格式修正。费用同时受单场及其历史版本、中央账本和当前批次限制。

“生成中，尚未核验”区域显示本次模型返回的可读文字。完整结果通过结构、引用和费用规则后才进入正式方案。失败或中断的草稿单独保留。网页搜索摘要用于寻找来源，正文提取后才参与有条件的证据判断。

## 材料与联网配置

检索覆盖当前版本完整已解析的文字、附件页和表格区域。用户选择的 PDF 页范围继续生效。材料按版本冻结，引用保留文件名、位置、片段哈希和语料快照哈希。排序使用 BM25，规划器负责提出具体问题与扩展查询。

默认联网来源为 DeepSeek。搜索和网页抓取使用现有 `DEEPSEEK_API_KEY`，兼容旧 `MODEL_API_KEY`。产品内的 MCP（Model Context Protocol，模型上下文协议）适配器注册只读搜索与抓取工具，由官方 TypeScript 客户端调用。服务端随后请求 DeepSeek 官方 Search / Fetch API。

在本机私有配置中设置以下非密钥参数。

```dotenv
ARENA_SEARCH_PROVIDER=deepseek
ARENA_TOOL_BATCH_ID=你的已批准固定批次标识
```

批次标识在重启后继续使用。每批最多 20 次模型请求、20 次联网调用，模型与工具合计估算最多 2 美元。中央账本原有限额仍然生效。新批次对应独立确认的额度，历史预留计入原账。

DeepSeek 官方分别列出每千次成功请求 0.75 美元和 5 元人民币的价格。当前代码保留两个参考价，按既有预算折算参数保守预留每次 0.000834 美元。已知失败或空响应按 0 结算，结果未知时保留预留。页面显示用量估算，实际消费以服务商账单为准。[官方说明](https://api-docs.deepseek.com/zh-cn/guides/search/)

可选的远程 Tavily MCP 使用以下配置。

```dotenv
ARENA_SEARCH_PROVIDER=tavily
TAVILY_API_KEY=在本机填写
TAVILY_USD_PER_CREDIT=0.008
```

Tavily 使用基础搜索和基础正文提取。每次提取 1 个网页，保守预留 1 credit。搜索源由配置明确选择，调用失败会留下对应状态。缺少密钥或批次配置时，页面保留本地材料推演，联网能力显示配置状态。[Tavily 文档](https://docs.tavily.com/documentation/mcp)

## 保存与找回历史

点击页眉的“我的历史”，可以查看当前浏览器身份下的讨论和未提交草稿。Cookie 负责日常识别，历史列表由服务端按身份返回。

首次保存恢复码时按以下顺序操作。

1. 点击“生成恢复码”。
2. 点击“下载保存”，保存恢复码文件。
3. 勾选已保存，再点击“已保存，启用新码”。
4. 换浏览器或清除 Cookie 后，打开“我的历史”，输入已保存的完整恢复码。

恢复码有访问该身份历史的权限，适合保存在自己的密码管理器或私有文件中。服务端保存哈希。重新生成并启用新码后，旧恢复码及旧设备 Cookie 失效。

恢复会切换当前查看的身份。已有两份身份时，先保存当前身份恢复码，再切换到另一份。已丢失 Cookie 且此前没有保存恢复码的记录，仍需原有有效凭据才能证明归属。

## 检查与真实验收

免费检查覆盖真实 SQLite、模型和搜索接口替身、MCP 协议、浏览器操作与移动视口。测试名称标出替身和合成任务。手机视口检查与真实手机检查分别记录。

```sh
pnpm typecheck
pnpm lint
pnpm test
node --test scripts/*.test.mjs
node scripts/validate-evals.mjs
pnpm build
PLAYWRIGHT_CHANNEL=chrome E2E_PORT=3100 pnpm test:e2e
```

`scripts/agent-smoke.ts` 默认只检查配置状态。显式传入 `--run` 后，使用合成任务执行真实自主推演、DeepSeek 联网和模型流式验收。调用方提供私有配置、原中央账本绝对路径与 `ARENA_ACCEPTANCE_BATCH_ID`，脚本只在独立验收目录创建应用数据库。

该脚本复用当前账本额度，保留原有未知请求，记录新增用量和原账本行哈希。协议完成、代理语义审查、真人评价和公网部署分别记录。
