# 演示模式

演示模式用于展示界面和推演流程。它不调用模型，不需要密钥，也不产生费用。

## 启动

在项目根目录运行：

```bash
pnpm demo
```

看到 `演示已启动` 后，在浏览器打开 `http://127.0.0.1:3002`。按 Ctrl+C 停止。

第一次启动要构建正式版，大约需要一分钟。之后代码没有变化时会直接启动。

可用的参数：

- `--rebuild`：强制重新构建。
- `--port=<端口>`：更换页面端口。默认端口是 3002，内部还会占用下一个端口（默认 3003）。

通过 pnpm 传参时写成 `pnpm demo --port=4000`。

## 演示内容

首页有 5 个试填示例，每个示例都有专属内容：三条路线、四次质疑、证据、修订和裁决。这些内容写在 `scripts/demo/scenarios.mjs`。

手动输入其他问题时，页面显示一份通用流程内容，裁决会说明没有分析这个问题。

要修改内容，直接编辑 `scenarios.mjs`，然后运行 `node --test scripts/demo.test.mjs`。这个测试检查引用的原话和算式结果是否一致。

## 展示时要说明的事

**演示内容不是模型结果。** 路线、证据、裁决、Token 数和费用都是预设的。页面底部的提示和右上角的按钮都写明了这一点，展示时也要向观众说明。

只有真实运行才能证明模型的效果。演示模式不能作为效果证据。

## 和真实运行的隔离

产品代码不引用 `scripts/demo/`。产品页面只读取 `/api/health` 返回的版本标记，在演示时显示对应的提示文字。

`scripts/demo/server.mjs` 自己回答全部 `/api` 请求，不转发给页面服务。页面服务启动时，模型相关的环境变量都设为空。`scripts/demo.test.mjs` 会检查 `/api` 请求没有被转发。
