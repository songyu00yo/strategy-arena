# 旧版演示模式

`pnpm demo` 展示旧版三路线讨论的预设流程。它不调用模型，不需要密钥，也不产生费用。当前五角色分析工作台通过 `pnpm dev` 进入，使用真实接口；这个演示不提供新工作台的模拟结果。

## 启动

在项目根目录运行：

```bash
pnpm demo
```

看到 `旧版演示已启动` 后，在浏览器打开 `http://127.0.0.1:3002/?legacy=1`。直接访问 `http://127.0.0.1:3002` 也会转入旧版。按 Ctrl+C 停止。

第一次启动会构建页面。后续启动会核对复制包的构建记录与当前源码指纹。源码、配置、依赖锁文件、提交或 Node.js 运行环境变化后，会重新构建；内容相同的未提交工作区也可以复用。

可用的参数：

- `--rebuild`：强制重新构建。
- `--port=<端口>`：更换页面端口。默认端口是 3002，内部还会占用下一个端口（默认 3003）。

通过 pnpm 传参时写成 `pnpm demo --port=4000`。

## 演示内容

旧版首页有 5 个试填示例，每个示例都有专属内容：三条路线、四次质疑、证据、修订和裁决。这些内容写在 `scripts/demo/scenarios.mjs`。

手动输入其他问题时，页面显示一份通用流程内容，裁决会说明没有分析这个问题。

要修改内容，直接编辑 `scenarios.mjs`，然后运行 `node --test scripts/demo.test.mjs`。这个测试检查引用的原话和算式结果是否一致。

## 展示时要说明的事

**演示内容不是模型结果。** 路线、证据、裁决、Token 数和费用都是预设的。页面底部的提示和右上角的按钮都写明了这一点，展示时也要向观众说明。

只有真实运行才能证明模型的效果。演示模式不能作为效果证据。

## 和真实运行的隔离

产品代码不引用 `scripts/demo/`。产品页面只读取 `/api/health` 返回的版本标记，在演示时显示对应的提示文字。

`scripts/demo/server.mjs` 自己回答全部 `/api` 请求，不转发给页面服务。未支持的新工作台接口返回 404，不生成模拟分析。页面服务启动时，模型相关的环境变量都设为空。`scripts/demo.test.mjs` 检查旧版入口、原有链接和 API 隔离。
